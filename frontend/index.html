规则说明

了解刘看山推荐的评审机制、打分规则和项目愿景

项目愿景

知乎社区中，大量优质内容因创作者粉丝数不足而难以获得足够的曝光。传统推荐算法往往倾向于推荐已有高互动量的内容，形成「马太效应」——强者愈强，新人难以出头。

「刘看山推荐」旨在打破这一困境。我们通过多 Agent AI 评审系统，从内容本身的质量出发，不看粉丝数、不看历史数据，纯粹评估内容的深度、原创性、可读性等维度，让真正优质的内容被看见。

核心理念：内容为王。一篇 0 粉丝作者写的深度技术文章，和一篇百万粉丝大V的随笔，在刘看山面前享有完全平等的评审机会。

评分维度

每篇内容由 6 位 AI 评审员（刘看山分身）从不同维度独立评分，最终加权计算综合得分：

维度评审员权重评估要点
内容深度学术刘看山20%论证是否充分、分析是否深入、是否有独到见解
原创性创意刘看山20%观点是否新颖、是否有独特视角、非简单搬运
可读性阅读刘看山15%结构是否清晰、语言是否流畅、排版是否友好
专业度专业刘看山15%术语使用是否准确、引用是否可靠、数据是否真实
社区价值社区刘看山15%是否能引发有价值的讨论、对社区是否有贡献
人类原创鉴真刘看山15%是否为人类原创内容、AI 生成内容检测

推荐规则

  • 推荐成功：综合评分 ≥ 7.0 分，内容将进入推荐榜，获得更多曝光机会
  • 有待提升：综合评分 5.0 ~ 6.9 分，系统会给出具体的改进建议
  • 暂未推荐：综合评分 < 5.0 分，建议重新打磨内容后再次提交

动态额度机制（核心玩法）

设计理念：新人创作者更需要推荐机会来验证内容质量，而资深创作者已经拥有足够的粉丝基础和内容积累。因此，系统会根据你的粉丝数和赞同数动态调整每月推荐额度——粉丝越少，额度越高；随名气增长，额度逐步降低，激励你用质量而非数量取胜。

冷知识：等级取粉丝数和赞同数两个维度中较高者决定。也就是说，即使粉丝不多，但你的回答获得大量赞同，一样可以升级！
每次额度奖励（推荐成功 +2、高分 +3）不受动态额度影响，所有等级用户统一享受。

内容要求

  • 支持知乎回答、文章、想法等内容类型
  • 禁止提交违规、抄袭、纯 AI 生成的内容
  • 同一内容不可重复提交

技术架构

本项目是参加「知乎 Hackathon | AI 脑洞实验室」的参赛作品，属于「引力场」赛道——聚焦社区内容分发与社交互动。

  • 后端：Python FastAPI + SQLite，调用知乎 API 获取内容
  • AI 评审：多 Agent 架构，6 个独立 AI 评审员并行评分
  • 前端：纯静态 HTML/CSS/JS，无框架依赖，轻量高效
  • IP 融合：以知乎吉祥物「刘看山」为核心 IP，打造评审团形象

为什么叫「刘看山推荐」？刘看山是知乎的官方吉祥物，我们让它化身为 6 位不同性格的 AI 评审员，组成「刘看山评审团」，用可爱又专业的方式为优质内容把关。
